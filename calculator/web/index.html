Can't be tested from a browser

A browser hides these on purpose. Run them from calculator/ (use python3 on macOS/Linux).

  • Missing Host header → 400

    Browsers always send Host, and fetch() is not allowed to remove it.

    python marker.py --full
    python -m unittest -v tests.test_server.TestMarker.test_task_list

  • Pipelining

    Browsers send one request at a time on an HTTP/1.1 connection and wait for its answer.

    python marker.py --pipeline
    python -m unittest -v tests.test_server.TestFraming.test_pipelining_six_at_once

  • A request sent byte by byte

    The browser, not the page, decides how bytes are split into TCP segments.

    python -m unittest -v tests.test_server.TestFraming.test_one_byte_at_a_time

  • Content-Length body framing

    A page can't put a POST body and the next request in one segment, so it can't show byte n+1 being left for the next request.

    python -m unittest -v tests.test_server.TestFraming.test_post_body_is_consumed_not_parsed tests.test_server.TestFraming.test_body_that_looks_like_a_request
